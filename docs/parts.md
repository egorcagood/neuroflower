# Детали

| Что | Количество | Уточнение |
|---|---:|---|
| ESP32-S3 N16R8 | 1 | В видео HW678 V6.0.0: 16 МБ flash, 8 МБ PSRAM; PSRAM здесь не используется |
| BH1750, модуль GY-30 | 1 | Освещённость; выводы VCC, GND, SCL, SDA, ADD |
| SHT30 / SHT3x, модуль | 1 | Температура и влажность воздуха; VIN, GND, SDA/RH, SCL/T |
| Аналоговый ёмкостный датчик влажности почвы | 1 | VCC, GND, AOUT; совместимый с питанием 3,3 В |
| Макетная плата | 1 | С двумя половинами и шинами питания |
| Провода Dupont | Набор, около 20 | Под ваши разъёмы: мама–папа, при необходимости мама–мама |
| Штыревые гребёнки | По модулям | Если не припаяны с завода |
| USB-кабель с передачей данных | 1 | Под USB-C на плате и разъём компьютера |
| Алоэ в горшке с дренажным отверстием | 1 | У нас Стёпа |

Для неприпаянных модулей нужны паяльник, припой и флюс. Мультиметр помогает проверить контакт и отсутствие замыкания. Электроника остаётся выше грунта и вдали от воды.

Для программной части: компьютер с USB и интернетом, Python 3.11+, VS Code с PlatformIO либо PlatformIO CLI, отдельный Telegram-бот от BotFather и OpenAI API key. VPS нужен только для серверного режима. Обычная Яндекс Станция сама по себе этот репозиторий не запускает: голосовой пример требует уже настроенного Саймона.
