# Публичный комплект, 24 ноября 2026

Рабочие исходники Telegram-бота и голосового форматирования сверены с установленной серверной версией. В комплект включены `spoken.py` и обновлённая голосовая ветка, где экранный текст отделён от речи. Настройки заменены примерами; база памяти, реальные ключи и прежние резервные копии flash не публикуются.

Проверка перед публикацией:

- 66 существующих тестов бота прошли на Windows / Python 3.12. Проверяются память, калибровка, уход, доступ владельца, приём измерений и голосовые команды.
- Чистый проект USB-прошивки собран PlatformIO 6.2.0 / Espressif32 6.12.0. Размер программы 313 897 байт, RAM 19 752 байта; образ сформирован для flash 16 MB.
- Обе схемы просмотрены, назначения линий сверены с GPIO в прошивке и фактической последовательностью сборки.
- В GitHub Actions добавлены тесты бота и сборка прошивки. Их результат смотрите во вкладке Actions; локальная проверка не заменяет проверку CI.

Этот публичный образ повторно на плату при упаковке не загружался. Работа трёх датчиков и разговор через колонку были ранее подтверждены в исходной сборке; пайка и подключения новой пользовательской сборки требуют своей проверки.

USB-режим публикуется как воспроизводимый основной вариант. Незавершённые эксперименты Wi-Fi не включены. Модули Саймона требуют интеграции с его отдельным проектом: полный проект колонки и его аудиотракт здесь не распространяются, а значит автономный тест колонки из этого репозитория невозможен.

Калибровка и границы ухода индивидуальны. Начальные пороги являются практическими эвристиками проекта, а не универсальными нормами для всех растений.
