# Свой Telegram-бот

## Локальный запуск: самый короткий путь

Требуется Python 3.11 или новее. Команды PowerShell ниже выполняйте из папки `bot`:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item config.local.example.json config.local.json
```

Откройте `config.local.json` и заполните:

- `telegram_token`: токен отдельного бота, созданного в @BotFather через `/newbot`.
- `bot_username`: его username без @. Приложение проверяет, что токен принадлежит этому боту.
- `owner_id`: ваш числовой Telegram user ID, именно число. Ответы разрешены только владельцу в личном чате.
- `openai_key`: свой OpenAI API key с доступным балансом.
- `model`: модель с поддержкой Responses API и изображений, доступная в вашем аккаунте. В исходной установке использована `gpt-5.4-mini`.
- `serial_port`: `auto` для одной поддерживаемой платы либо реальный COM-порт, например `COM6`.
- `data_dir`: папка памяти. `./state` создаст её относительно рабочей папки; для службы лучше абсолютный путь.

Чтобы узнать свой ID без стороннего бота: напишите новому боту `/start`, пока приложение ещё не запущено, выполните `python owner_id.py` и вставьте токен в скрытый ввод. Скрипт читает ожидающие личные сообщения, печатает только ID отправителей; он ничего не отправляет и не подтверждает обновления.

Закройте Serial Monitor и запустите:

```powershell
.\.venv\Scripts\python.exe bot.py --config config.local.json
```

На Linux/macOS: `python3 -m venv .venv`, затем `.venv/bin/python -m pip install -r requirements.txt` и `.venv/bin/python bot.py --config config.local.json`. Скопируйте пример обычной командой `cp`.

Откройте своего бота, нажмите «Запустить». Введите `/plant` с описанием растения, горшка и грунта. Затем настройте [калибровку](../docs/calibration.md). Команды:

| Команда / кнопка | Что делает |
|---|---|
| Как ты? / обычное сообщение | Разговор со Стёпой |
| Показатели / `/readings` | Числа с единицами и свежесть измерения |
| Фото в личный чат | Разбор снимка вместе с известным состоянием |
| `/plant описание` | Сохранение профиля растения |
| `/calibrate`, `/dry`, `/wet` | Настройка шкалы почвы |
| `/threshold 25` | Порог просьбы о проверке, не команда полива |
| Я полил | Подтверждение и запись полива |
| `/watered YYYY-MM-DD HH:MM` | Запись прошедшего полива, время по Москве |
| `/history` | История поливов |
| `/pause`, `/resume` | Остановка и возврат инициативных напоминаний |

Часовой пояс правил и истории — Москва. Один бот запускается только в одном экземпляре: либо локально, либо на VPS. Не запускайте одновременно мост, монитор и локальный бот на одном COM-порту.

## Приватность и память

SQLite в `data_dir` хранит историю, калибровку, поливы и измерения. Для переноса остановите процесс и сохраните папку памяти целиком. Не заменяйте свежую серверную базу старой локальной копией.

Текст и присланное фото передаются OpenAI для ответа; Telegram получает сообщения через Bot API. Параметр `store:false` относится к запросу API и не означает отсутствия локальной памяти. Файлы с ключами и базу данных нельзя добавлять в публичный репозиторий. Ограничение `daily_ai_limit` — число запросов в день, не лимит расходов в рублях.

Профиль и калибровку каждый настраивает для своего растения. Предустановленных реальных поливов и личной переписки нет. Для постоянной работы можно настроить планировщик задач на Windows; скрытый автозапуск на чужом компьютере этот комплект сам не устанавливает.

## Сервер и голос

См. [VPS](../docs/server.md) и [Саймон](../integrations/simon/README.md). У Telegram и голоса одна память, но отдельные адаптеры. Ядро персонажа находится в `character.py`, правила ухода — в `care.py`, понятная озвучка чисел и дат — в `spoken.py`.
